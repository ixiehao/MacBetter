# Site fonts

This site self-hosts the following fonts. They are all licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/), which permits commercial use, embedding, modification, and redistribution subject to the license terms.

- **Inter Variable** — [official source](https://github.com/rsms/inter), kept as `InterVariable.woff2`.
- **Noto Sans SC** — [official Google Fonts source](https://github.com/google/fonts/tree/main/ofl/notosanssc), subset from the official variable font for the text currently shipped by this site.
- **Noto Sans JP** — [official Google Fonts source](https://github.com/google/fonts/tree/main/ofl/notosansjp), subset from the official variable font for the text currently shipped by this site.

The original OFL notices are retained in `LICENSES/`. When the site copy gains characters, regenerate the two Noto subsets from their official sources so every glyph remains available.
